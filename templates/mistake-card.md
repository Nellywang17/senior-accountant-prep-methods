# 错题卡模板

用途：用户报来错题或写错因时使用。一张卡一道题/一个考点，按间隔重复回炉。

## 卡片格式

| 字段 | 内容 |
|---|---|
| 编号 | MC-[日期]-[序号] |
| 大纲定位 | 第 X 部分／印刷页 N／能力要求 [掌握/熟悉/了解] |
| 知识点原文 | （从 195 条清单摘原句，不改写） |
| 错因分类 | 审题偏差／知识点未掌握／定位太慢／计算失误／表述失分 |
| 正确思路关键词 | （3–5 个词，供自评对照） |
| 题源 | A官方／B回忆版(非官方原题)／C机构／D自编(依据大纲第X部分) |
| 状态 | 草稿／已审阅／待核验 |
| 首次记录日 | YYYY-MM-DD |
| 回炉间隔 | 1 / 3 / 7 / 14 天（按反馈动态调整） |
| 下次回炉日 | 按 `algorithm.js` 的 `nextInterval` 计算 |

## 生成规则

- 大纲定位必须查 `knowledge-points-2026.md`；查不到写"清单无此条"，不编造页码。
- 存疑答案标"待核验"，不进入小测与模考。
- 新卡一律"草稿"，用户确认"已审阅"才进组卷。
- 回炉反馈用"忘了／模糊／记得"，不用对错二分。

## 汇总输出：错因分布

按错因分类计数，做横向条形（纯文本即可）：

```
知识点未掌握  ████████  8
定位太慢      █████     5
审题偏差      ███       3
计算失误      ██        2
表述失分      █         1
```
