# 案例题得分点式自评框架

用途：用户写完案例题答案后，按此框架自评。评分不依赖真题原文，只用官方大纲的能力等级与三类考点性质。教练不代判真实考试分数。

## 一、三类考点与评分口径

| 类型 | 大纲能力等级 | 评分口径 | 典型失分 |
|---|---|---|---|
| 判断分析型 | 掌握／熟悉 | 结论先行 + 依据（准则/规定关键词）+ 对应到案例事实 | 只给结论无依据；依据与事实脱节 |
| 计算型 | 掌握 | 列计算过程 + 关键参数 + 结果 | 只写结果无过程；参数取错 |
| 表述型 | 了解／熟悉 | 关键词命中 + 分点罗列 | 大段散文无分点；关键词缺 |

评分规则（与官方阅卷口径对齐的部分）：
- 文字题：与标准答案关键词**意思一致即得分**，不要求逐字相同。
- 计算题：要求列过程的，未列过程但结果正确得一半分；过程对结果错，得一半分；未要求列过程的，结果正确即得分。

## 二、自评步骤

1. **定位考点**：答案涉及哪几个大纲条目？写出"第 X 部分／印刷页 N"。定位不到的，说明该答案可能跑题。
2. **拆得分点**：按三类口径，把答案拆成"结论/依据/过程/关键词"若干点，每点标命中（✓）或漏（✗）。
3. **算命中率**：命中点数 / 应有点数。按部分汇总。
4. **归类失分**：审题偏差／知识点未掌握／定位太慢／计算失误／表述失分。
5. **定下一步**：漏点转错题卡；表述失分练"结论+依据"两段式；计算失误回教材例题。

## 四、答题结构模板（供练习，不是押题）

**判断分析型**：
```
结论：________（先给判断）
依据：________（准则/规定关键词，带出处）
结合案例：________（引用案例事实对应依据）
```

**计算型**：
```
参数：________（列出已知条件）
公式：________
过程：________（逐步列式）
结果：________
```

**表述型**：
```
① ________（关键词开头）
② ________
③ ________
```

## 五、边界

- 框架是方法层原创，不构成官方评分标准；真实阅卷以当年官方为准。
- 不出题、不预测考题、不写押题。用户须自带题目与答案。
- 教练可帮拆得分点与归类失分，但不代判真实考试分数。
- 涉及具体分值权重时说明"官方未公布各题分值"，不编造分值。
