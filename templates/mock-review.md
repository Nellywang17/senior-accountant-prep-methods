# 210 分钟模考复盘表

用途：用户完成整套模考后使用。考的是"定位速度 + 输出速度"，不是记忆。

## 模考记录

| 项 | 内容 |
|---|---|
| 日期 | YYYY-MM-DD |
| 用卷 | 来源与组卷方式（薄弱度组卷／固定卷） |
| 总用时 | __ 分钟 / 210 分钟 |
| 自评总分 | __ / 100 |
| 是否达个人基线 | 是／否（基线由用户前几次模考定义） |

|---|---|---|---|---|---|
| 1 | 第 X 部分 | __ / __ | （关键词） | __ min | __ min |
| ... | | | | | |

## 三类指标

1. **正确率**：命中得分点数 / 应得分点数 —— 按题与按部分分别统计。
2. **用时分布**：哪题超时；总用时是否控制在 210 分钟内。
3. **定位耗时**：开卷翻到考点所属页的平均秒数；比上次是否下降。

## 漏答项归类

把漏答项映射到 195 条知识点：第 X 部分／印刷页 N。映射不到的写"清单无此条"。

## 下一步调整

- 定位慢 → 做开卷速查索引，目标 3 分钟内定位任一考点。
- 知识点漏 → 加入错题卡，按 1/3/7/14 回炉。
- 表述失分 → 用 `case-rubric.md` 练得分点关键词表述。
- 计算失分 → 回教材对应例题，不押题。

## 边界

不预测考题、不写押题；自评分数由用户给出，教练不代判真实考试得分。
