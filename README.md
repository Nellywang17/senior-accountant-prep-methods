# 高级会计师备考 · 方法模板（开源）

**190+ 条官方大纲考点，19 周怎么排、错题怎么回炉、案例题怎么给自己打分——这套模板把"备考方法"变成可复用的表格。**&#8203;

面向 2027 年高级会计师（《高级会计实务》）考生。开卷考案例分析题，拼的不是背书，是**定位速度＋输出结构**。这套模板解决三个实际问题：

- 不知道自己从哪起步 → **起点诊断**：5 问定位基础/时长/薄弱，自动分层给方案
- 每周不知道该干什么 → **周报 + 阶段复盘**：六项固定内容，三指标看进度
- 题做了但不知道错在哪 → **错题卡 + 案例题自评**：错因分类、1/3/7/14 天回炉、得分点拆解

## 你能拿走什么

| 模板 | 解决的问题 |
|---|---|
| 起点诊断 | 5 问自动分 L1/L2/L3，给 19 周三阶段方案与教材/视频/做题/索引配比 |
| 周报 | 六项固定内容＋下周任务，每周日 10 分钟填完 |
| 错题卡 | 错因归类＋知识点定位＋回炉日期，按 1/3/7/14 天滚动 |
| 模考复盘 | 逐题漏答、用时、定位耗时三项，找出"会但做不完"的卡点 |
| 阶段复盘 | 正确率、薄弱章 TOP3、用时三个指标，P1/P2/P3 各做一次 |
| 案例题自评 | 判断/计算/表述三类得分点框架，对照关键词给自己打分 |

全部为 Markdown，可直接复制进笔记软件或打印使用。

## 为什么这样设计

高会大纲对每条知识点标注"掌握／熟悉／了解"三个能力等级，开卷考试的核心是把精力放在★重点上，并能在考场上快速翻到位置。这套模板围绕两件事展开：**按等级分配时间**，以及**用错题和复盘持续修正方向**。不押题、不保过，只给可验证的方法。

## 说明

模板为方法层原创，可自由使用。知识点解释须带出处；不含教材正文、真题与机构题库。知识内核基于 2026 版大纲，2027 版发布后须差异核对。2027 考务日程未公布，报名、合格线、考试日期以财政部会计资格评价中心及本省财政厅当年公告为准；评审以属地或单位评委会当年通知为准。
