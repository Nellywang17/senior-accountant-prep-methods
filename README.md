# 高级会计师备考 · 方法模板（开源版）

本仓库公开的是**备考方法模板**：起点诊断、周报、错题卡、模考复盘、阶段复盘、案例题自评框架。这些是可自由使用的方法层内容。

完整的**高会备考专家**（含 2026 版官方大纲 195 条知识点、11 章章节地图、19 周任务表、可运行的速测与间隔重复脚本）以付费形式发布在 WorkBuddy 开放平台，名称「高会备考教练」。

## 目录

| 文件 | 用途 |
|---|---|
| `templates/intake-questionnaire.md` | 起点诊断问卷：基础/时长/目标/薄弱/考区五项，输出起点速览 |
| `templates/weekly-report.md` | 周报六项固定内容＋下周任务 |
| `templates/mistake-card.md` | 错题卡：错因＋知识点＋1/3/7/14 天回炉 |
| `templates/mock-review.md` | 210 分钟模考复盘表：逐题漏答＋用时＋定位耗时 |
| `templates/phase-review.md` | 阶段复盘：三指标＋薄弱章 TOP3 |
| `templates/case-rubric.md` | 案例题得分点式自评框架（判断/计算/表述三类） |

## 使用原则

- **零编造**：知识点须带出处（大纲第 X 部分／印刷页 N），不编造题目、不押题、不保过。
- **题源分级**：A 官方／B 回忆版（标"非官方原题"）／C 机构（自行上传）／D 自编（标"依据大纲第 X 部分"）。
- **区分事实与判断**：大纲条目、政策日期是事实；"快速过／重点补"是备考建议。

## 边界声明

- 本开源版**不含** 195 条知识点全文、官方教材正文、历年真题与机构题库。
- 知识内核基于 **2026 版**官方大纲；2027 版发布后须差异核对。
- 2027 考务日程未公布，报名、合格线、考试日期以财政部会计资格评价中心及本省财政厅当年公告为准；评审以属地或单位评委会当年通知为准。
